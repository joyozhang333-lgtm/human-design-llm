# 人类图 Web/App 产品需求文档

更新时间：2026-05-30

## 1. 产品定义

人类图 Web/App 是一个简体中文的身体资源与灵性能量顾问。用户输入出生日期、出生时间、出生地或时区后，系统生成标准 BodyGraph、核心属性、中心/通道/闸门解读，并支持围绕职业、关系、表达、能量管理和现实决策继续追问。

产品不把人类图包装成医疗、心理诊断、投资建议或确定性命运预测。它的定位是自我观察、身体资源识别、能量管理和灵性反思工具。

## 2. 用户路径

1. 用户进入首页，看到出生资料输入、精度说明和产品边界。
2. 用户填写出生日期、时间、城市/省份/国家或 IANA 时区。
3. 系统调用排盘内核，返回 `HumanDesignChart`、精度提示和 BodyGraph SVG。
4. 用户在报告页切换总览版、身体能量版、职业版、关系版、深度解读版。
5. 用户在聊天区输入具体问题，系统基于当前图表事实、知识卡和会话上下文回答；配置 DeepSeek 后由 DeepSeek 生成自然语言答案。
6. 用户可为报告生成一张 MiniMax 视觉封面；正式 BodyGraph 仍由固定 SVG 模板输出。
7. 用户可复制/导出 Markdown 报告；后续版本再加入账号、历史档案、PDF 和分享链接。

## 3. 功能需求

### 3.1 排盘与精度

- 正式排盘必须具备出生日期、出生时间、出生地/时区。
- 仅生日不可生成正式 BodyGraph，只返回补全引导。
- 输入支持显式 IANA 时区，也支持城市/地区/国家解析。
- 输出必须包含 `precision_warnings`，上层 UI 必须展示。

### 3.2 BodyGraph 出图

- 使用固定 SVG 模板，不从零随机绘图。
- 图中必须展示九大中心、已定义/开放状态、红黑激活、通道、闸门和两侧人格/设计行星列表。
- 中文术语必须统一：荐骨中心、荐骨权威、阿姬娜中心、喉咙中心、人生角色。
- 禁止回退到密集黑点式图形表达。

### 3.3 解读报告

- 总览版：帮助用户先看懂类型、策略、权威、人生角色、定义和轮回交叉。
- 身体能量版：重点解释九大中心、通道、闸门、身体资源、灵性能量、消耗模式和练习。
- 职业版：解释工作方式、赚钱结构、角色定位、合作边界和方向筛选。
- 关系版：解释情绪、边界、沟通、连接方式和互动节奏。
- 深度解读版：把总览与身体能量合并成可长期阅读的完整解读。

### 3.4 聊天问答

- 问答必须绑定 `chart_id`。
- 系统根据问题自动推断 focus：职业、关系、决策、成长/能量或总览。
- 回答必须基于当前 chart facts、reading sections、context blocks 和 citations。
- 不允许编造用户图中不存在的中心、通道或闸门。
- 配置 `DEEPSEEK_API_KEY` 后走 DeepSeek；未配置或失败时回退本地结构化解读。

### 3.5 AI 视觉封面

- 配置 `MINIMAX_API_KEY` 后可生成报告封面/能量视觉。
- 图片模型只生成视觉封面，不承担正式 BodyGraph 排盘责任。
- Prompt 必须带入真实图表摘要、已定义/开放中心和主要通道，同时明确禁止生成错误闸门数字或密集文字。

## 4. 已落地接口

- `POST /api/charts`：创建人类图，返回 chart、BodyGraph SVG、精度提示。
- `GET /api/charts/{chart_id}`：读取图表。
- `GET /api/charts/{chart_id}/bodygraph.svg`：读取 SVG 图。
- `POST /api/reports`：生成报告。
- `POST /api/chat`：围绕当前图表追问。
- `POST /api/images/reading-visual`：生成 MiniMax 报告视觉封面。
- `GET /api/product/config`：读取产品配置、术语和精度策略。
- `GET /api/product/providers`：读取 DeepSeek / MiniMax 的非敏感配置状态。

详细契约见 `docs/contracts/web-api.md`。

## 5. 验收标准

- 用户可从 Web 表单完成排盘、看图、读报告、继续追问。
- API 不破坏已有 `HumanDesignChart` 和 `LLMProductPackage` 契约。
- 术语测试不得出现“骶骨中心、额骨中心、阿扎那”等非目标表达。
- BodyGraph SVG 必须包含两侧信息、中心、通道和闸门。
- 聊天回答必须基于当前问题和图表事实，并返回 citations 和 followups。
- MiniMax 未配置时不阻塞核心流程；配置后返回可展示图片 URL 或 data URL。
- 自动化测试覆盖排盘 API、报告 API、聊天 API、身体能量内容和术语一致性。
