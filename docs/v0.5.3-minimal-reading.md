# Human Design V0.5.3：极简阅读与内容审核

## 目标

V0.5.3 解决两个问题：结果页信息堆叠过多，主题报告结构比内容本身更抢注意力。改版后，用户先看到 BodyGraph 和六项必要配置，再选择身体、财富、天赋、关系或使命报告；中心与闸门列表不再出现在主阅读页。

## 页面结构

- 主阅读页：BodyGraph、六项必要配置、一段全盘解读、五份主题报告入口、咨询对话。
- 主题报告：标题、结论、四个核心问题、现实表现、需要留意、可执行尝试、继续咨询。
- 不再展示：主页面中心列表、闸门目录、专业配置抽屉、主题报告事实标签、封面大卡、目录、诊断网格和多层行动卡。

## 内容规则

- 每份用户报告固定回答四个问题，每章只承载一个核心结论。
- 多条通道必须先综合再解释，不能为每条通道重复套用同一份“天赋、盲区、卡住、练习”模板。
- 用户可见正文不展示提示词、验证器、回退策略等内部语言；专业事实保留在 API 和咨询上下文中做核验。
- 人类图只作为自我观察工具。内容审核验证盘面事实、区分度、可读性和可执行性，不把它包装成科学诊断或确定性预测。

## 自动审核

`human_design.content_audit.audit_report_content()` 对五份报告检查：四章结构、盘面可追溯、通道覆盖、内容区分度、正文长度、行动建议和内部语言污染。自动评分必须达到 90 分以上，同时仍需完成桌面端、移动端和真实交互人工评审。
