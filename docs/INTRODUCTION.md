## One-Line English

Human Design LLM is the open-source product behind HumanDesign.guichu.chat: a BodyGraph calculator, whole-chart reading engine, DeepSeek-powered consultant, Web app, API, and installable AI Agent Skill.

## 一句话中文

Human Design LLM 是 HumanDesign.guichu.chat 的完整开源产品，覆盖 BodyGraph 排盘、全盘综合解读、天赋与使命地图、DeepSeek 咨询、Web/API 与可安装的 AI Agent Skill。

## Short English Introduction

Human Design LLM helps developers build Human Design AI assistants and BodyGraph interpretation agents. It calculates Human Design charts from birth data, converts the result into a stable JSON schema, then generates source-backed readings and LLM-ready product packages with prompts, context blocks, citations, follow-up questions, delivery depth, and session state.

Unlike prompt-only Human Design tools, this project separates chart calculation, knowledge references, interpretation logic, BodyGraph rendering, empirical validation, and evaluation gates. It is designed for AI products that need grounded chart facts and falsifiable quality checks instead of generic spiritual copy.

## 中文短介绍

Human Design LLM 帮助开发者构建人类图 AI 解读助手和 BodyGraph 解释 Agent。它会根据出生资料计算人类图，把结果转换成稳定的 JSON schema，再生成带知识卡来源的结构化解读和 LLM 产品包，包括 prompts、上下文块、引用、后续追问、输出深度和会话状态。

它不是单纯的 prompt 模板，而是把排盘、知识库、解读逻辑、BodyGraph 出图、科学验证协议和评测门槛拆开维护，适合需要“先有盘面事实，再让大模型解读”的 AI 产品。

## Long English Introduction

Human Design LLM is an LLM-native product layer for Human Design. It wraps chart calculation, BodyGraph data modeling, interpretation references, source citations, focus-aware answer generation, and runtime-ready skill packaging into one Python repository.

The core output is not just a markdown reading. The project can produce a full LLM product package containing chart facts, reading sections, source references, assistant instructions, context blocks, answer citations, suggested follow-ups, delivery depth, and session state. This makes it suitable for AI agents, API backends, prompt orchestration systems, and local Codex/OpenAI-style skills.

The current V0.6 release places the BodyGraph first, removes top-level center and gate catalogues, and turns the result into one editorial reading path. Six essential facts, a dedicated channel reading, and five focused reports open instantly. DeepSeek powers grounded follow-up consultation, while deterministic validators and content audits block invented chart facts, repeated templates, prompt leakage, and developer language. The same audited Agent Skill installs into Codex, Claude Code, DeepSeek Harness, Hugging Face / OpenClaw-compatible hosts, and Tencent WorkBuddy.

## 中文长介绍

Human Design LLM 是一个面向大模型的人类图产品层。它把人类图排盘、BodyGraph 数据结构、知识卡引用、来源追踪、焦点化回答生成和 runtime skill 打包在同一个 Python 仓库里。

这个项目的核心输出不只是 Markdown 解读，而是一份完整的 LLM 产品包：包含 chart 事实、阅读章节、来源引用、助手指令、上下文块、回答引用、推荐追问、输出深度和会话状态。因此它适合 AI Agent、API 后端、prompt orchestration、Codex/OpenAI 风格技能，以及任何需要结构化人类图事实的大模型应用。

当前 V0.6 版本把 BodyGraph 放在结果页首屏，从顶层删除中心与闸门目录，只保留六项核心配置、三条全盘结论、独立通道解读和五份即时打开的主题报告。报告采用单栏文章和渐进展开，DeepSeek 负责基于当前盘面的连续咨询，确定性护栏与内容审核负责拦截虚构盘面事实、重复模板、提示词泄漏和开发者语言。同一份标准 Agent Skill 可安装到 Codex、Claude Code、DeepSeek Harness、Hugging Face / OpenClaw 兼容宿主和腾讯 WorkBuddy。
