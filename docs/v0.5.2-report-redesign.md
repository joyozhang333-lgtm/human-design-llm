# Human Design V0.5.2：主题报告重构

## 问题

V0.5 的解读地图存在两个直接影响使用的问题：

1. 打开地图时同步等待大模型生成，首屏被 10-60 秒模型延迟阻塞。
2. 身体、天赋、财富、关系、使命共用相似的诊断卡结构，虽然字段完整，但主题之间差异不够，读起来像模板。

## 产品目标

- 点击主题后 500 毫秒内看到完整报告首屏；后端地图生成目标 p95 小于 300 毫秒。
- 五份用户报告分别成篇，不用一套模板替换标题。
- 每份报告至少四章，先给结论，再给盘面依据、现实场景、偏离状态和可执行验证。
- DeepSeek 保留给主动追问和真实咨询对话，不再阻塞静态报告。

## 报告结构

### 身体报告

1. 决定系统：类型、Strategy、Authority 如何组成行动顺序。
2. 稳定能量：逐个说明已定义中心能提供什么资源。
3. 压力入口：逐个说明开放中心会放大什么现实压力。
4. 恢复顺序：从退出压力场到重新决定的具体步骤。

### 财富报告

1. 财富主线：机会入口、人生角色和稳定能力如何共同形成收入。
2. 可变现能力：每条已定义通道单独说明能解决什么问题、适合怎样交付。
3. 定价与承诺：按开放中心指出低价、多做、赶工、避免冲突等利润漏洞。
4. 资产化路径：用 30 天把一次能力转成案例、流程、产品或转介绍。

### 天赋报告

1. 天赋发现：重点解释人生角色为什么会让用户忽略或误用天赋。
2. 稳定天赋：每条已定义通道单独成项，不只给通道名称。
3. 天赋组合：说明稳定中心怎样为通道供能。
4. 成熟路径：把天然八十分能力练成可被稳定选择的一百分能力。

### 关系报告

1. 连接方式：人生角色、定义、Strategy 和 Authority 如何共同影响关系入口。
2. 情绪与冲突：区分情绪波和情绪放大，给出暂停与回谈方式。
3. 吸引与盲区：逐个说明开放中心容易把什么误认为爱或安全感。
4. 适配条件：用可观察的相处条件替代抽象的“最适合什么类型”。

### 使命报告

1. 使命主题：明确轮回交叉名称及人格/设计太阳地球四个位置。
2. 承担方式：用类型、Strategy、Authority 和人生角色解释使命怎样发生。
3. 落地能力：每条稳定通道说明怎样成为长期贡献的工具。
4. 现实验证：用 90 天的生命力、能力积累和真实影响验证主线。

## 交互与性能

- `POST /api/interpretation-maps` 只做确定性排盘解读，返回 `generation_mode: instant`。
- 前端在主报告稳定后空闲预取五份主题报告，点击时优先读内存缓存。
- 加载提示延迟 160 毫秒显示，避免快速响应时闪烁。
- 追问按钮仍进入 `/api/chat`，并带入当前报告和条目上下文，由 DeepSeek 做继续分析。
- 正式站的 SPA HTML 设置 `Cache-Control: no-cache`；带 hash 的静态资源可长期缓存，避免旧 V0.4 首页滞留。

## 验收

- 五份报告均包含至少四章，且章节标题、内容和练习互不套用。
- 有已定义通道时，天赋、财富、使命报告逐条覆盖真实通道。
- 身体报告覆盖所有已定义中心和所有开放中心。
- 使命报告显示真实轮回交叉名称和四个太阳/地球位置。
- 地图接口不得调用外部模型；离线环境和线上环境响应结构一致。
- 移动端正文不小于 18px，长文不出现双栏挤压。
- 任何报告不得出现 prompt、chart facts、fallback、validator 等内部语言。
