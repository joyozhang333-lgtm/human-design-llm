# Human Design V0.6: Readable Product Redesign

V0.6 is a structural redesign of the user product. It replaces the previous stacked dashboard/report layout with a single editorial reading flow and upgrades the repository from prompt-level compatibility to tested Agent Skill packages.

## User Experience

- The BodyGraph is the first result, not a secondary illustration.
- The chart summary contains only six essential configurations and a short explanation for each.
- Defined centers, open centers, and gate catalogues are removed from the top-level result page.
- Channels receive a dedicated section with one interpretation per actual channel and one whole-chart synthesis.
- Topic reports open instantly from deterministic chart-grounded content.
- Reports reveal one chapter at a time and keep supporting diagnosis behind explicit reader actions.
- Follow-up questions enter the consultation thread with the current chart and report context.

## Content Quality

The automated audit no longer rewards a fixed four-card template. It checks factual traceability, map-specific coverage, repetition, generic filler, paragraph length, actionable observation, and internal-language pollution. A passing score is an engineering quality gate, not evidence that Human Design is scientifically validated.

## Agent Distribution

The canonical `skills/human-design/` bundle follows the Agent Skills `SKILL.md` format. The installer supports project or user scope for:

- OpenAI Codex
- Claude Code
- DeepSeek Harness
- shared Agent Skills / Hugging Face-compatible hosts
- OpenClaw-compatible shared skills
- Tencent WorkBuddy / CodeBuddy

WorkBuddy also receives a deterministic ZIP package for its local skill upload flow. Integration tests verify paths, required metadata, package contents, and the absence of secrets or personal birth data.
